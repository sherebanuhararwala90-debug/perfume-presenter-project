# Sarkar Fragrance Showcase

Create a clean, modern, multi-page website for [INSERT BRAND NAME] in the [INSERT PRODUCT CATEGORY] category, featuring their hero product: [INSERT HERO PRODUCT].

### PAGE 1: Home Page
Create a primary landing page containing:
1. Header & Navigation: Brand logo, navigation links to "Home", "Product Details", "Reviews", "Contact", and a "Shop Now" call-to-action button.
2. Hero Section: Catchy headline, a one-line value proposition featuring the brand, a main hero banner visual, and a primary CTA button.
3. Category Showcase Grid: A section highlighting main product categories or features relevant to the brand's space.
4. Social Proof: Customer ratings, 2-3 testimonial cards, and brand trust badges (e.g., "Fast Shipping", "Satisfaction Guaranteed").
5. Footer: Navigation links, social media icon placeholders, brand copyright, and basic contact information.

---

### PAGE 2: Product Detail Page (/product)
Create a dedicated product page specifically for the brand's hero product containing:
1. Product Gallery Showcase (Top Section):


Left side: Large primary hero product visual with 3 smaller thumbnail preview placeholders underneath.

Right side: Full product title, price tag, star rating summary, variant selectors (e.g., color, size, or flavor options), and a prominent "Add to Cart / Buy Now" button.
2. Key Benefits & Features: A grid highlighting 3 to 4 clear user benefits of the hero product.
3. Specifications Table: A clean, structured table listing product details and specs relevant to the product category.
4. Final Call-to-Action: A closing section prompting the user to order, with a repeated CTA button.
